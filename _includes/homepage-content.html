Research Interests

I work on long-horizon agents and the systems that help them learn and improve, especially:

(i) Long-horizon agents: CLI and open-ended workflows with JarvisHub, Claw-Eval-Live, and JarvisX-Cowork.

(ii) Agentic RL & harness generalization: trajectory rollout, rubric and verifier design, feedback-driven learning, and harness generalization in Seed2.0, OpenSearch-VL, JarvisIR, JarvisArt, and Gen-Searcher.

(iii) Self-improving agents / RSI: Auto R&D and AI-for-AI through skill, data, rubric, and harness evolution in the Seed2.1 Auto R&D Agent ("Seed-for-Seed"), JarvisEvo, and GenEvolve.

Open-Source Project
JarvisHub: An Open Harness for Canvas-Native Creative Agents
Project Paper Hugging Face GitHub 机器之心 新智元

JarvisHub is an open harness for canvas-native creative agents. It turns an editable canvas into persistent project state, giving agents shared memory, structured actions, and traceable feedback for long-horizon creative workflows.

CVPR 2026 (Tencent HY)
JarvisEvo: Towards a Self-Evolving Photo Editing Agent with Synergistic Editor-Evaluator Optimization
PDF Project HF Paper GitHub

JarvisEvo couples an editor and evaluator in a self-evolving loop for long-horizon photo editing. Reward shaping and reflection-driven updates let the agent improve its editing policy over time.

CVPR 2025
JarvisIR: Elevating Autonomous Driving Perception with Intelligent Image Restoration
PDF Project Online Demo GitHub

JarvisIR post-trains a vision-language agent with mixed-rank reward feedback to plan and coordinate restoration experts. It connects tool use with reward-aligned learning for downstream driving perception.

NeurIPS 2025
JarvisArt: Liberating Human Artistic Creativity via an Intelligent Photo Retouching Agent
PDF Project HF Paper Twitter YouTube Bilibili GitHub

JarvisArt plans multi-step retouching commands and coordinates expert tools for controllable photo editing. Its interpretable subgoals turn artistic retouching into a long-horizon agent workflow.

Preprint 2026
Gen-Searcher: Reinforcing Agentic Search for Image Generation
PDF Project GitHub

Gen-Searcher trains an agent to search for visual evidence before image generation. Reinforcement learning over search trajectories improves composition and semantic faithfulness beyond one-shot prompt tuning.

Preprint 2026
Claw-Eval-Live: A Live Agent Benchmark for Evolving Real-World Workflows
PDF Project HF Paper GitHub

Claw-Eval-Live is a continuously refreshed benchmark for real-world agent workflows, built around verifiable execution traces. It measures how reliably agents complete evolving tasks rather than static demonstrations.

Open-Source Project
JarvisX-Cowork: A Personal AI Creative Assistant for End-to-End Creative Workflows
GitHub Demo Video

JarvisX-Cowork is an open-source assistant for end-to-end creative workflows, from reference search and generation to refinement, video, and final deliverables. A shared planner, memory, and tool interface keep long-horizon production coherent.
