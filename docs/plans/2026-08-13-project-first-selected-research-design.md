# Project-First Selected Research Design

## Goal

Make the homepage explain each project before presenting publication metadata. The Selected Research section should read like a compact academic project portfolio rather than a sequence of author lists.

## Approved direction

Apply the project-first presentation to every Selected Research entry:

- remove all author lists and team-credit lines, including the long JarvisHub author list and `ByteDance Seed Team`;
- keep the existing project order, thumbnails, venue or project badges, titles, and resource links;
- give every entry a concise one- or two-sentence description of the problem, system, and agent/RL/RSI significance;
- keep Seed2.1 and Seed2.0 inside their combined ByteDance Seed row, with short contribution-focused descriptions;
- preserve the current blue-gray academic visual language and bracketed resource links.

## Information hierarchy

Each entry follows the same reading order:

1. project or venue badge and visual;
2. project title;
3. resource links;
4. concise project description.

Seed2.1 and Seed2.0 retain their nested titles, descriptions, and links inside the merged Seed entry.

## Content rules

- Start with what the project does, not who authored it.
- Use plain, specific language and avoid paper-abstract density.
- Keep each description to at most two short sentences.
- Emphasize long-horizon agents, agentic RL, harnesses, evaluation, or self-improvement where that framing is genuinely supported.
- Do not add claims, metrics, links, projects, or visual elements beyond the existing material.

## Verification

- No Selected Research entry contains author names or team-credit text.
- All existing project titles, badges, visuals, and resource links remain present.
- JarvisHub remains first and retains its six resource links.
- The merged Seed row still contains exactly two subprojects.
- Desktop and mobile layouts remain readable without horizontal overflow.
- The generated Jekyll site and deployed GitHub Pages page both satisfy the same content checks.
